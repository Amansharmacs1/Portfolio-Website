# Aman Sharma - Portfolio

A modern, highly interactive, and fully responsive personal portfolio website built to showcase my projects, experience, skills, and publications. 

## 🌐 Live Website
View the live portfolio here: [https://Amansharmacs1.github.io/Portfolio-Website/](https://Amansharmacs1.github.io/Portfolio-Website/)

## 🛠️ Tech Stack
- React 18 & Vite
- Tailwind CSS 
- Framer Motion
- Lucide React

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Amansharmacs1/Portfolio-Website.git
   cd Portfolio-Website/frontend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

Open your browser and navigate to `http://localhost:3000`.
